# Laboratory 01 – Welcome to the Cloud

# Mission Overview

This laboratory activity is the first Cloud Computing mission for CCM101. The goal is to prepare a Linux environment, learn basic Linux commands, document technical work, and create a Cloud Computing Portfolio using GitHub.

The activity uses the KillerCoda Playground to provide a cloud-based Linux environment. The work completed in this mission will become part of my Cloud Computing Portfolio for the semester.

## Objectives

* Access and use a cloud-based Linux environment through KillerCoda.
* Explore and navigate the Linux operating system.
* Gather basic system information.
* Organize files and directories using Linux commands.
* Create and maintain a GitHub repository.
* Document technical work using Markdown.
* Practice proper documentation for cloud computing activities.

## Activities Performed

I launched an Ubuntu Linux Playground using KillerCoda and verified that the terminal was working correctly.

I created a new Linux user named `jquimson`, gave the user sudo privileges, and logged in to the new account.

I checked the current username, working directory, and hostname. I also investigated the Linux distribution, kernel version, CPU information, total memory, and available disk space.

I created the required folders and Markdown files for the laboratory activity. I also created a public GitHub repository for my Cloud Computing Portfolio and organized the laboratory files inside the repository.

## Linux Commands Used

* `whoami` – Displays the current username.
* `pwd` – Displays the current working directory.
* `hostname` – Displays the system hostname.
* `adduser` – Creates a new Linux user.
* `usermod` – Modifies a user account and adds sudo privileges.
* `su` – Switches to another user account.
* `cat` – Displays the contents of a file.
* `uname -r` – Displays the Linux kernel version.
* `lscpu` – Displays CPU information.
* `free -h` – Displays memory information.
* `df -h` – Displays disk space information.
* `mkdir` – Creates directories.
* `touch` – Creates empty files.
* `nano` – Creates and edits text files.
* `ls` – Lists files and directories.
* `cd` – Changes the current directory.
* `cp` – Copies files and directories.
* `git clone` – Downloads a Git repository.
* `git status` – Displays the current Git repository status.

## Skills Learned
I learned how to use a Linux terminal and basic Linux commands. I also learned how to create users, folders, and files. I learned how to check system information and use GitHub to store my laboratory work.
