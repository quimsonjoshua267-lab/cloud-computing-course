## Questions

### 1. Which cloud provider offers the broadest range of services?

I think AWS has the widest range of services. It has many options for storage, servers, databases, networking, and more.

### 2. Which provider best integrates with Microsoft technologies?

Azure is the best for Microsoft technologies. It works well with Windows Server, Microsoft 365, and other Microsoft products.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

I think Google Cloud is strong in AI and Kubernetes. It provides many AI tools and Google Kubernetes Engine.

### 4. Which cloud platform would you personally choose and why?

I would choose AWS because it has many services and is flexible. I think it would be useful for both small and large projects.
