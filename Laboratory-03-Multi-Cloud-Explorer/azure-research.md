Microsoft Azure Research
Brief Overview

Microsoft Azure is a cloud platform created by Microsoft. It allows businesses to run applications, store information, manage servers, and use other cloud services.

Global Infrastructure

Azure has data centers around the world. Its infrastructure is organized into different Regions and availability options. This allows businesses to choose locations that are closer to their users.

Cloud Management Console

The Azure Portal is the main website used to manage Azure services. Users can create and manage virtual machines, databases, storage, networks, and other resources.

Four Core Services
Azure Virtual Machines – Provides virtual computers for running applications.
Azure Blob Storage – Stores files and other large amounts of data.
Azure SQL Database – Provides a managed SQL database.
Azure Virtual Network – Creates a private network for Azure resources.
Three Advantages
Works well with Microsoft products.
Supports both cloud and on-premises systems.
Provides many different cloud services.
Typical Enterprise Use Cases

Businesses use Azure for Windows applications, databases, websites, Microsoft services, hybrid cloud systems, backups, and enterprise applications.
