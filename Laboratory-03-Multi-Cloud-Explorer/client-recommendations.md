# Client Recommendations

## Client A – Startup Company

**Recommended Platform: AWS**

AWS is a good choice because the startup has a limited budget but expects to grow. AWS allows the company to start small and increase its resources when needed.
It can also support a mobile application as the number of users grows.

**Useful Services:**

* Amazon EC2
* Amazon S3
* Amazon RDS

---

## Client B – University

**Recommended Platform: Microsoft Azure**

Azure is a good choice because the university already uses Microsoft products. Azure works well with Windows Server, Microsoft 365, and Active Directory.
This can make moving some university services to the cloud easier.

**Useful Services:**

* Azure Virtual Machines
* Azure SQL Database
* Microsoft Entra ID

---

## Client C – AI Research Company

**Recommended Platform: Google Cloud**

Google Cloud is a good choice because the company focuses on Artificial Intelligence and Machine Learning. It provides tools that can support AI projects and high-performance workloads.
It also supports Kubernetes for modern applications.

**Useful Services:**

* Compute Engine
* Vertex AI
* Google Kubernetes Engine (GKE)

---

## Client D – Global E-Commerce Company

**Recommended Platform: AWS**

AWS is a good choice for a global e-commerce company because it can support applications around the world. Its services can scale when there are many customers using the website.
It can also help keep the online store available.

**Useful Services:**

* Amazon EC2
* Amazon S3
* Amazon RDS





## Checkpoint 5

# Cloud Service Matching

This table shows similar services offered by AWS, Azure, and Google Cloud.

| Service Category    | AWS | Azure              | GCP            |
| ------------------- | --- | ------------------ | -------------- |
| Virtual Machine     | EC2 | Virtual Machines   | Compute Engine |
| Object Storage      | S3  | Blob Storage       | Cloud Storage  |
| Identity Management | IAM | Entra ID           | Cloud IAM      |
| SQL Database        | RDS | Azure SQL Database | Cloud SQL      |
| Kubernetes          | EKS | AKS                | GKE            |

## Simple Explanation

These services do similar jobs but have different names depending on the cloud provider. For example, EC2, Azure Virtual Machines, and Compute Engine are all used to run virtual machines. This makes it easier to compare the three cloud platforms.
