AWS Research
Brief Overview

Amazon Web Services (AWS) is a cloud platform from Amazon. It provides different services that businesses can use for running applications, storing data, and managing servers online.

Global Infrastructure

AWS has data centers located around the world. These are organized into Regions and Availability Zones. This helps businesses run their applications in different locations and improve availability.

Cloud Management Console

The AWS Management Console is a website where users can manage their AWS services. For example, users can create servers, storage, databases, and networks from the console.

Four Core Services
Amazon EC2 – Provides virtual servers for running applications.
Amazon S3 – Stores files and other data in the cloud.
Amazon RDS – Provides managed relational databases.
Amazon VPC – Creates a private network for AWS resources.
Three Advantages
AWS has a large number of cloud services.
It can easily scale resources when demand changes.
It has a large global infrastructure.
Typical Enterprise Use Cases

Businesses use AWS for websites, mobile applications, databases, file storage, backups, data processing, and large online systems.
