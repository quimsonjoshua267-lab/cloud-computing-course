# Mission Reflection

This activity helped me understand AWS, Azure, and Google Cloud better. Before doing this activity, I mostly knew that they were cloud platforms, but I did not know much about the differences between them. The platform that impressed me the most was AWS because it has many services and can be used for different types of projects.

AWS, Azure, and GCP are similar because they all provide services like virtual machines, storage, databases, and networking. They also allow users to use cloud resources without having to manage all the physical hardware themselves. Even though they offer similar services, each platform has its own strengths.

I also learned that business needs are important when choosing a cloud platform. For example, Azure would be a good choice for a company that already uses Microsoft products. Google Cloud can be useful for AI and Machine Learning projects, while AWS can be a good general choice because of its many services.

Acting as a Cloud Solutions Consultant helped me realize that choosing a cloud provider is not just about picking the most popular one. I need to consider the company's budget, existing technology, goals, and future growth before making a decision.

My GitHub Cloud Computing Portfolio also improved because I added information about AWS, Azure, and GCP. I also added comparison tables, client recommendations, and my Linux investigation results from KillerCoda. Overall, this activity gave me a better understanding of how cloud platforms can be used to solve different business needs.
